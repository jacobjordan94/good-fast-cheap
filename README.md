> Fast, good, cheap: you can only pick two.

A small interactive take on the project-management triangle. Flip on any two
switches; try to flip on the third and one of the others gives way.

## Running locally

```bash
npm install
npm run dev
```

## Scripts

| Command                | Does                          |
| ---------------------- | ----------------------------- |
| `npm run dev`          | Start the dev server          |
| `npm run build`        | Typecheck and build to `dist` |
| `npm run preview`      | Serve the production build    |
| `npm run lint`         | Lint with ESLint              |
| `npm run typecheck`    | Typecheck with TypeScript     |
| `npm run format`       | Format with Prettier          |
| `npm run format:check` | Check formatting (used in CI) |

## Built with

React 19, TypeScript, Vite, Tailwind CSS v4, and shadcn/ui (Base UI).
